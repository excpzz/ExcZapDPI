# ExcZapDPI
ExcZap — это утилита для обхода блокировок, созданная с единственной целью: помочь людям восстановить доступ к сервисам, сайтам и приложениям, которые перестали работать.  Я сделал этот проект, чтобы у каждого была простая и удобная возможность пользоваться интернетом без ограничений.
